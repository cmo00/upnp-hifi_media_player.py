# upnp-hifi_media_player.py
A terminal shell based python3 audio-player that streams audio files to connected network DACs (tested with one ifi and one Yamaha DAC). Also works with usb connected DACs,but "n" for next track "b" for previous while playback is currently still under construction for usb mode (while in directory of the player use terminal start with  python3 hifi_player_v4_6_3.py --dir Path/to/your/files --usb quit with "q"). UPnP is fully functional (start with  python3 hifi_player_v4_6_3.py --dir Path/to/your/files). Features on-the-fly .aiff to .wav conversion (so far no .dsf support)
